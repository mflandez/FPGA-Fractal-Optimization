# FPGA Fractal Rendering Optimization 

## 📌 Overview
This project involved optimizing a fractal rendering application for an FPGA platform (DE-10 board) by implementing custom instructions in VHDL and optimizing C++ code. The goal was to improve frame rates while maintaining precision.

## 🛠 Technologies
- **Hardware:** VHDL, Quartus, NIOS II
- **Software:** C++, Eclipse, ModelSim
- **Platform:** Intel DE-10 FPGA Board

## 📁 Contents
- `doc/rapport.pdf`: Final project report (in French)
- `doc/etape.pdf`: Intermediate project report (in French)
- (Optional) `src/`: Source code (VHDL & C++)

## 🎯 Key Results
- Achieved a reduction in execution time from **55.13s to 7.86s** for fractal calculations.
- Implemented two custom instructions (ASM1 & ASM2) for fractal level computation and pixel drawing.
